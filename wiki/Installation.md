# Installation

## Prerequisites

- Ubuntu 22.04 LTS installed
- ROS 2 Humble installed ([official guide](https://docs.ros.org/en/humble/Installation/Ubuntu-Install-Debs.html))
- `colcon` build tools installed:
  ```bash
  sudo apt install python3-colcon-common-extensions
  ```

## Step 1: Install System Dependencies

```bash
# ROS 2 packages
sudo apt update
sudo apt install -y \
  ros-humble-ur-robot-driver \
  ros-humble-moveit \
  ros-humble-realsense2-camera \
  ros-humble-tf2-ros \
  ros-humble-tf2-geometry-msgs \
  ros-humble-tf2-py \
  ros-humble-message-filters \
  ros-humble-cv-bridge \
  ros-humble-rqt-image-view \
  ros-humble-rviz2 \
  ros-humble-ros2-controllers-test-nodes

# System libraries (required for canvas_pose_detector C++ build)
sudo apt install -y \
  libopencv-dev \
  python3-opencv \
  libeigen3-dev \
  python3-numpy
```

### Optional: MoveIt Python bindings

Only needed if you want to run the `canvas_pose_follower` validation node:

```bash
sudo apt install ros-humble-moveit-py
```

## Step 2: Clone the Repository

```bash
mkdir -p ~/RS2
cd ~/RS2
git clone git@github.com:StephenUTS/XR_Teleoperation.git
```

The workspace structure after cloning:

```
~/RS2/XR_Teleoperation/
├── src/
│   ├── canvas_pose_detector/     # Camera perception (C++ & Python) -- Johan
│   ├── ur_unity_bringup/         # UR3e driver + Unity bridge (Python) -- Stephen
│   └── ROS-TCP-Endpoint/         # Unity-ROS TCP server (Python) -- 3rd party
├── build/                        # (generated by colcon)
├── install/                      # (generated by colcon)
└── log/                          # (generated by colcon)
```

## Step 3: Install ROS Dependencies

```bash
cd ~/RS2/XR_Teleoperation
source /opt/ros/humble/setup.bash
rosdep install --from-paths src --ignore-src -r -y
```

## Step 4: Build

```bash
cd ~/RS2/XR_Teleoperation
colcon build --symlink-install
```

Expected output (no errors):

```
Starting >>> canvas_pose_detector
Starting >>> ros_tcp_endpoint
Starting >>> ur_unity_bringup
Finished <<< ros_tcp_endpoint [1.23s]
Finished <<< ur_unity_bringup [1.45s]
Finished <<< canvas_pose_detector [12.3s]

Summary: 3 packages finished [13.5s]
```

> **Note:** `canvas_pose_detector` takes longer (~12s) because it compiles a C++ node with OpenCV and Eigen3 dependencies. The other two packages are pure Python.

## Step 5: Source the Workspace

Add this to your `~/.bashrc` so the workspace is sourced automatically:

```bash
echo "source ~/RS2/XR_Teleoperation/install/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

Or source manually each time you open a new terminal:

```bash
source ~/RS2/XR_Teleoperation/install/setup.bash
```

## Step 6: Verify Installation

```bash
# Check all three packages are found
ros2 pkg list | grep -E "canvas_pose_detector|ur_unity_bringup|ros_tcp_endpoint"
```

Expected output:

```
canvas_pose_detector
ros_tcp_endpoint
ur_unity_bringup
```

Quick smoke test -- run the sim pipeline (no hardware needed):

```bash
ros2 launch canvas_pose_detector canvas_sim_pipeline.launch.py
```

After ~12 seconds you should see `[canvas_stroke_corrector] Status: OK` in the terminal. Press Ctrl+C to stop.

## Step 7: Build Individual Packages (optional)

If you only modified one package:

```bash
# Canvas perception only (C++ rebuild ~12s)
colcon build --packages-select canvas_pose_detector --symlink-install

# UR Unity bridge only (Python, <2s)
colcon build --packages-select ur_unity_bringup --symlink-install

# ROS-TCP-Endpoint only (Python, <2s)
colcon build --packages-select ros_tcp_endpoint --symlink-install
```

> **Tip:** Python packages built with `--symlink-install` use symlinks to the source files. Editing Python source files takes effect immediately without rebuilding. C++ code always requires a rebuild.

## Hardware Setup

### RealSense D435if

1. Mount the camera to the UR3e wrist/flange using a 3D-printed or machined bracket
2. Connect via **USB 3.0** cable and port (USB 2.0 will not provide depth data at full resolution)
3. Verify the camera is detected:
   ```bash
   rs-enumerate-devices | head -20
   ```
   You should see the device serial number and firmware version.
4. Test the ROS 2 driver:
   ```bash
   ros2 launch realsense2_camera rs_launch.py enable_sync:=true align_depth.enable:=true
   ```
   Verify topics exist:
   ```bash
   ros2 topic list | grep camera
   ```
   Expected: `/camera/camera/color/image_raw`, `/camera/camera/aligned_depth_to_color/image_raw`, `/camera/camera/color/camera_info`

### AprilTag Canvas

1. Go to https://chev.me/arucogen/
2. Select dictionary: **AprilTag 36h11**
3. Set marker size: **50 mm** (minimum for reliable detection at 1.5 m)
4. Print markers with IDs: **0** (top-left), **1** (top-right), **2** (bottom-right), **3** (bottom-left)
5. Affix markers to the four corners of an A4 sheet in **landscape** orientation:

```
[ID:0  TL] ─────────────────── [ID:1  TR]
    |                               |
    |         A4 Canvas              |
    |        297 x 210 mm           |
    |        (landscape)            |
    |                               |
[ID:3  BL] ─────────────────── [ID:2  BR]
```

6. Ensure markers are:
   - Printed at the correct size (measure with a ruler -- exactly 50 mm)
   - **Flat** and firmly attached (curled markers degrade detection significantly)
   - On the **front face** of the canvas
   - Using the correct dictionary (AprilTag 36h11, not ArUco or other dictionaries)

### UR3e Robot

1. Connect the UR3e controller to the workstation via Ethernet
2. Configure the robot's IP address (default setup assumes `192.168.1.x` subnet)
3. On the UR teach pendant, load the external control URCap program
4. See the [UR Robot Driver documentation](https://github.com/UniversalRobots/Universal_Robots_ROS2_Driver) for detailed setup

### Hand-Eye Calibration

> **Status: Not yet complete.** The launch files use placeholder values for the `flange -> camera_color_optical_frame` transform.

The static TF published in `canvas_real_pipeline.launch.py` uses these defaults:

```
x=-0.05  y=0.00  z=-0.09  roll=0.0  pitch=1.0  yaw=0.0
```

Before real robot use, perform hand-eye calibration and update these values:

```bash
ros2 launch canvas_pose_detector canvas_real_pipeline.launch.py \
  cam_x:=<measured_x> cam_y:=<measured_y> cam_z:=<measured_z> \
  cam_roll:=<measured_roll> cam_pitch:=<measured_pitch> cam_yaw:=<measured_yaw>
```

## Unity Setup

1. Open the Unity project (2022.3 LTS) on the same machine or a machine on the same network
2. Install **ROS-TCP-Connector** from the Unity Robotics Hub
3. Configure the connector:
   - **ROS IP Address:** The Ubuntu machine's LAN IP (find with `hostname -I | awk '{print $1}'`)
   - **ROS TCP Port:** `10000`
4. The `ros_tcp_endpoint` node starts automatically with every pipeline launch file
